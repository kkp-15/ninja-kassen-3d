# ずんだもん音声の作り方（手作業・1回だけ）

phase1.txt〜phase6.txt は hakodate-1869.html の `phases[].textZ` と同一の読み上げ原稿。
これを VOICEVOX で WAV に書き出して、このフォルダに置く。

## 手順（Mac版 VOICEVOX GUI）

1. https://voicevox.hiroshiba.jp/ から VOICEVOX をダウンロード・インストール
2. アプリを起動し、話者に「ずんだもん（ノーマル）」を選ぶ
3. phase1.txt の本文を1行目のテキスト欄に貼り付ける
   - 行を分けると別ファイルに分割書き出しされるので、1局面=1テキスト欄にまとめる
4. 再生して読み（イントネーション・「開陽丸＝かいようまる」等の固有名詞）を確認
5. メニュー「ファイル」→「選択音声を書き出し」で WAV 保存
6. ファイル名を `phase1.wav` にリネームしてこのフォルダに置く
7. phase2〜phase6 も同様に繰り返す

## 命名と動作仕様

- `voice/phase1.wav` 〜 `voice/phase6.wav`（HTMLと同階層の voice/ フォルダ）
- 音声ONのとき局面切替で自動再生。ファイルが無くてもエラーにはならない
- モバイルは「音声」ボタンをタップしてONにした後でないと再生されない（ブラウザの自動再生制限）

## 公開前の確認（必須）

- VOICEVOX 利用規約とずんだもん（東北ずん子・ずんだもんプロジェクト）の
  公式利用ガイドラインを確認すること（広告収益サイトでの利用条件を含む）
- クレジット表記「VOICEVOX:ずんだもん」はHTML側で音声/ずんだもん解説ON時に表示される（削除しない）
